# ⚽ FIFA World Cup 2026 — Data Analytics & Interactive Dashboard

An end-to-end **Data Analytics project** exploring the FIFA World Cup 2026 through web-scraped data, data cleaning, analysis, and an interactive Power BI dashboard.

The project combines **Python, Beautiful Soup, Pandas, Power BI, DAX, HTML, and CSS** to transform raw web data into an interactive football analytics experience.

---

## 📌 Project Overview

The goal of this project was to collect and analyze FIFA World Cup 2026 data and present meaningful information through an interactive and visually engaging dashboard.

The data was collected from **Wikipedia** through web scraping, cleaned and prepared with Python, then analyzed and visualized using Power BI.

## 🧹 Data Preparation

The project started with raw information collected from web pages.

Using **Beautiful Soup**, the required information was extracted from the source website.

Pandas was then used to prepare the data for analysis, including tasks such as:

* Cleaning raw scraped data
* Structuring datasets
* Preparing columns for analysis
* Handling data inconsistencies
* Preparing data for Power BI

---

## 🧠 Analysis

After preparing the data, it was imported into Power BI for modeling and analysis.

The analysis focuses on areas such as:

* Tournament statistics
* Teams
* Players
* Groups
* Matches
* Stadiums
* Attendance
* Referees
* Tournament performance
